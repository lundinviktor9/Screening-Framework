# Code Audit — 2026-07-05

Full audit of frontend (`src/`), backend (`extractor/`, `underwrite/`), and repo hygiene.
Every "dead" claim was verified by tracing the import graph from the entry points and
grepping repo-wide for the symbol before listing it here.

---

## 0. Railway vs localhost (the deploy question)

`npm run app` is the **local dev workflow** (webpack :5173 + uvicorn :8787) and will always
be localhost — deploying changes nothing about it. Phase 3 produced the deploy *artifacts*
(Dockerfile, railway.json, docs/DEPLOY.md) but the actual deploy is a one-time manual step
in Railway's dashboard (create project from the GitHub repo, attach a `/data` volume, set
env vars). Until that's done there is no cloud URL. Once deployed, the app lives at
`<service>.up.railway.app` — independent of `npm run app`.

## 1. Critical bugs (fix first)

| # | Issue | Where |
|---|-------|-------|
| 1 | **Silent data-wipe path in deal store.** `read_all()` returns `[]` on a corrupted `deals.json`; the next `add()` then overwrites the file with a single deal — all deals permanently lost. Docstring claims file locking; there is none, so concurrent requests can also lose writes. | `extractor/persistence.py:39-43, 68-116` |
| 2 | **Showcase map never renders.** `MapCard` looks for `(window as any).mapboxgl`, which nothing ever sets (no CDN script; the npm import doesn't create a global). | 3 | **Path traversal on upload filenames.** `temp_{file.filename}` / `raw_{file.filename}` are used unsanitised — a crafted filename (`../../…`) escapes the target dir and writes anywhere. Also no extension/content-type validation. | `extractor/server.py:265`, `extractor/underwrite_routes.py:331` |
| 4 | **`/ingest-folder` reads arbitrary directories.** `PROJECT_ROOT / folder_path` — `..` and absolute paths win, so any host directory can be globbed and its PDFs sent to the Anthropic API. | `extractor/server.py:341` |
| 5 | **Regenerate can silently null the showcase.** `_extract_pdf_text` swallows all exceptions and returns `""`; Claude then gets an empty document and the showcase is overwritten with nulls, no error surfaced. | `extractor/showcase_routes.py:212-223` |
| 6 | **Full Python traceback returned in HTTP 500** on Mode B failure (info disclosure), and `mode_b_error.log` is written to the repo root (read-only/ephemeral in the container). | `extractor/underwrite_routes.py:444-454` |

## 5. Error handling & robustness (medium)

- No timeouts on Anthropic SDK calls (`extractor.py:66`, `showcase_enrichment.py:102`,
  `normalise_auto.py:264`) — one `/ingest` can hang ~10 min per SDK defaults.
- LibreOffice recalc failures discard soffice stderr (`adapter.py:99-103` → re-wrapped at
  `underwrite_routes.py:293-296`) — undiagnosable when it breaks.
- Showcase image static mount failure: bare `except: pass` (`server.py:112-115`) — photos would 404 silently.
- `showcase_enrichment.py:268-271` returns `{}` on bad Claude JSON (silent all-null showcase) while
  `extractor.py:101-102` correctly raises — inconsistent.
- `UnderwriteStepper.tsx:196` fetch without `r.ok` check; stale-closure risk in memoized columns
  (`DealDataTable.tsx:373`) and `UnderwritePage.tsx:27` (filter changes won't re-filter).

## 6. Auth (deploy-relevant)

Middleware gate itself is sound (all routes covered when `APP_USERS` set; signed httponly cookie).
Three gaps before real deploy:
- Open redirect: `next=//evil.com` passes the `startswith("/")` check (`auth.py:206`).
- Rate limiter keys on `request.client.host` but uvicorn runs without `--proxy-headers`, so on
  Railway every client is the proxy IP — one attacker's failures lock out everyone.
- Unset `SESSION_SECRET` silently generates an ephemeral one (all sessions die on restart).

## 7. Tests

`tests/test_underwrite_regression.py` is a real golden-regression harness but nothing runs it
(no CI, no `test` script, argparse-style so pytest collects zero tests). TASKS.md claims
Starlette TestClient coverage for auth/SPA/healthz that **does not exist**.
